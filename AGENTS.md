# Daybreak Coffee

This is a small, dependency-free demo, not an online shop.

- Use Bun. Run `bun run dev` from the current checkout.
- `server.ts` serves `web/index.html` with Bun's HTML bundler.
- Hero and page structure: `web/index.html`.
- Styling: `web/style.css`.
- Menu data and rendering: `web/menu.js`.
- Original illustrations: `web/assets/`.
- Keep everything local: no packages, CDNs, external fonts, services or payments.
- Preserve accessible names, keyboard navigation and mobile layout.
- Do not commit or push unless explicitly requested.
